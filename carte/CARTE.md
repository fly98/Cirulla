# Carte — provenienza e licenza

Mazzo francese usato da `burraco.html`. 55 file WebP 200x300, generati da SVG.

- **52 carte numerali e figure** — set *English pattern* di **Dmitry Fomin**,
  Wikimedia Commons, **CC0** (pubblico dominio, nessun obbligo di attribuzione).
  Categoria: `Category:SVG English pattern playing cards`.
- **JK-r / JK-b (jolly) e BACK (dorso)** — disegnati per questo progetto.
  I jolly non esistono nel set Fomin; i set trovati su Commons erano LGPL o GFDL,
  quindi sono stati rifatti a mano per tenere l'intero mazzo senza vincoli.

Rigenerazione: scaricare gli SVG dalla categoria Commons, rasterizzare a
200x300 con cairosvg e salvare in WebP q82. Le figure originali pesano
~190 KB l'una in SVG (2,3 MB il mazzo): in WebP l'intero set sta in ~380 KB.

Nomenclatura: `{indice}{seme}.webp` con indice A,2..10,J,Q,K e seme s,h,d,c.
Esempi: `As.webp`, `10h.webp`, `Kc.webp`. Più `JK-r`, `JK-b`, `BACK`.
